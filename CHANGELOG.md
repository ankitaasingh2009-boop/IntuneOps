# Changelog

All notable changes to IntuneOps will be documented in this file.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-14

### Added

- **Get-AutopilotDiagnostics** — Collect Autopilot enrollment status, deployment profiles, ESP configuration, and enrollment failures
- **Find-IntuneDrift** — Compare live Intune configuration profiles against a saved baseline and report drifts
- **Get-ComplianceReport** — Pull device compliance state, non-compliant reasons, and export HTML/CSV reports
- GitHub Actions CI with Pester tests
- Per-tool documentation under `docs/`
